# 小车台账 · 本地版 v1.2

双击桌面的 **小车台账**，或本目录的 **启动小车台账.cmd**。程序会启动仅本机可访问的服务，并打开默认浏览器。重复打开会复用当前服务。

## 首次安装（新克隆或下载源码）

准备 Windows、64 位 Python 3.13 和桌面浏览器。在项目目录打开 PowerShell，执行：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\启动小车台账.cmd
```

安装依赖时需要联网，完成后可在本机离线使用。桌面入口可创建为指向“启动小车台账.cmd”的快捷方式。

首次启动会在本地生成独立的演示台账与空白正式台账。仓库只保存源码、测试及必要资源；台账数据库、账号资料、购买截图、发票、备份、恢复密钥及虚拟环境均不随 Git 上传。后续更新源码时，本地 `data/` 中的记录会保留。

## 开始使用

1. 首次打开是**演示台账**，门店、编号、收支和账号全部为虚构资料，可以试操作。
2. 切到**正式台账**，设置至少 8 个字符的解锁密码。正式台账从空记录开始。
3. 下载恢复密钥并单独保管；它可以在忘记密码时重设密码。普通备份不会包含这份明文密钥。
4. 先建门店，登记入库并逐套输入或扫描编号，再做出库、装车及整车出货。

## 常用操作

- **收支**：只登记方向、金额、日期、分类、备注和附件。收入分类为“甲方回款”；支出分类为“PCBA采购、结构件采购、研发耗材、吃饭、差旅、出货耗材”。收入用红色，支出用淡绿色区分。旧记录的摘要合并显示在备注中，历史分类仍可原样保留。
- **入库**：点击“PCBA入库”或“结构件入库”，分别登记对应类型，编号每行一个，也可连续扫码。入库只管理日期、编号、数量和备注，不会生成收支。支出请在收支账本单独记录。
- **账单附件**：可以选择文件、拖入文件，或在附件区域按 Ctrl+V 粘贴图片。保存前可以移除选错的附件。图片、PDF 支持鼠标悬停预览，也可以点击预览按钮查看。PDF 使用随程序附带的 PDF.js 在本地渲染；不上传文件、不依赖浏览器 PDF 插件。单个文件最大 50 MB。
- **列表快速查看**：在收支账本主列表，把鼠标放到“附件 N 份”上即可直接预览，不用先打开详情。多份附件可在预览框内切换，PDF 支持翻页。右侧详情打开后，点击左侧空白区域可以关闭。
- **门店编码与账号备忘**：门店编码可以自行填写，前导零和大小写会保留；车辆和出货仍跟随原门店。联系人、电话、地址等资料照常填写。账号备忘改为一份自由文本，点击打开后可自行记录路由器、密码、远程账号等，正文会加密保存。首次打开可带入已有账号，原始旧记录仍保留；保存空白文档即表示清空当前备忘，不会再次带入旧账号。
- **扫码出库**：选择用途（装车领用/门店备件），扫码枪输入编号并回车，也可以手输和搜索。加入待确认清单后检查并确认。扫码本身不会立即出库。
- **组成成品车**：PCBA、结构件可分别领用，稍后用车架号绑定 PCBA 号。结构件编号就是车架号。
- **出整车**：选择门店和已配对车辆，可以一次发多台；不会再次扣配件库存。
- **换板**：选择新板及旧板去向。门店已有备件用于当地车辆时，不会重复出库；旧板只有明确退库才增加仓库可用量。
- **转店/备件调拨**：选择目标门店并保留原始关系和日期。跨店备件应先调拨，再用于该店车辆。
- **安装资料**：按名称（例如地图、安全池、安装图）新增资料项；同一门店、同一资料项再次上传会替换旧文件。若保存失败，旧文件仍保留。账单等可以添加多个附件。每文件最大 50 MB。
- **更正**：普通资料可编辑。收支可作废；出货满足未发生后续操作时可撤销，库存可退库、返修或报废。已发生后续业务的记录不能强行回改。

## 密码与数据

服务只监听 `127.0.0.1`，不向云端上传资料。账号记录中的用户名、密码、地址和备注使用 AES-GCM 加密，解锁密码经 Scrypt 派生密钥；随机数据密钥只在解锁时保留于进程内存。账号名称可见，账号详情默认隐藏。正式台账接口、附件和备份均需解锁；30 分钟无操作后需重新解锁。退出服务会清除解锁会话。

普通账目和附件以数据库、文件保存，**不是全磁盘加密**；请像保管财务文件一样保管程序目录和备份。解锁密码和恢复密钥都遗失时，加密账号无法恢复。改密码不改变已下载旧备份的密码。

- 正式数据：`data/live/ledger.sqlite3` 与 `data/live/attachments/`
- 演示数据：`data/demo/`，与正式数据隔离
- 日志：`logs/server.log`，不记录密码和账号详情

## 备份与恢复

设置中导出完整 ZIP，包含一致的数据库快照、有效附件及加密密钥封装；不会包含明文解锁密码或恢复密钥。导入前会校验格式、文件完整性、数据库和密码/恢复密钥，校验失败不会覆盖当前数据。正式与演示备份不互相导入。成功恢复正式数据后重新解锁。

安装资料更新不保留可浏览旧版；旧的完整备份仍可能包含备份当时的文件。建议定期把完整备份复制到另一块磁盘。

## 本机服务

关闭网页不会停止服务，可再次双击桌面入口继续使用。在“设置与备份”中停止服务后，下次双击会重新启动。启动器使用空闲本机端口，不占用其他程序端口。

程序使用独立 `.venv`；不会修改小车调试工具的环境。前端为原生 HTML/CSS/JavaScript，后端为 Python 3.13、aiohttp、SQLite、cryptography。第一版为单机单管理员，不提供云端、手机访问、地图编辑或应收应付核算。

开发验证：`.\.venv\Scripts\python.exe -m unittest discover -s tests -v`。
